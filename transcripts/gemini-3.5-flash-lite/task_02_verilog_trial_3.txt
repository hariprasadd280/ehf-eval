Write a synthesizable Verilog module named 'clk_divider' with ports: input wire clk, input wire rst, output reg clk_out. The module divides clk by 4 using asynchronous active-high reset. Return ONLY raw Verilog code inside a markdown verilog code block.

========================================

```verilog
module clk_divider (
    input wire clk,
    input wire rst,
    output reg clk_out
);

    reg [1:0] count;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            count   <= 2'b00;
            clk_out <= 1'b0;
        end else begin
            if (count == 2'b01) begin
                clk_out <= ~clk_out;
                count   <= count + 2'b01;
            end else if (count == 2'b11) begin
                clk_out <= ~clk_out;
                count   <= 2'b00;
            end else begin
                count   <= count + 2'b01;
            end
        end
    end

endmodule
```
